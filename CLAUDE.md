# Agents working in redox-rpi/redox-rpi

This repository belongs to the GitHub organisation
[redox-rpi](https://github.com/redox-rpi) (Redox OS on the Raspberry Pi).
The same rules apply in every repository of the organisation. They are
written down once, in the project management plan:
https://github.com/redox-rpi/redox-rpi/blob/main/docs/process/pmp.md
(roles, merge rights, "All repositories"), and in
https://github.com/redox-rpi/redox-rpi/blob/main/CONTRIBUTING.md

In short:
- Code goes through a branch and a pull request that names its issue;
  only those with the merge right merge (PMP, Merge rights).
- Docs (README, docs/) go straight to the default branch.
- No force push and no deletion of the default branch (ruleset protect-main).
- Issues and comments in short, plain English.

Owner session: the project lead (coordinator); each topic has its owner in the PMP.
Only what differs from these rules belongs in this repository's own docs.
