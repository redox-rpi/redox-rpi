# RFCs

Design proposals for larger changes, before any code is written. Each RFC
says what problem it solves, how, what it does not do, and in which steps
it could land. An RFC starts as **Draft**; the maintainer marks it
**Accepted** or **Rejected**.

| RFC | Title | Status |
|---|---|---|
| [0001](0001-identity-and-secure-channels.md) | Identity and secure channels as small schemes | Draft |
| [0002](0002-project-structure.md) | Project structure: clean up, split the repositories, fit a session's context | Accepted |
