**Second alpha.** Redox OS on the Raspberry Pi 3 Model B+. Programs now
start far more reliably. New are firmware information, a clock that is set
from the network, and a first network driver for the Pi Zero 2 W. Still an
alpha: for trying it out and for helping, not for daily use.

It replaces v0.1.1-alpha, which was never published because its image froze
on a real Pi.

This is an **unofficial, AI-assisted fork** and not part of the Redox OS
project. Please report problems here, not to Redox.

## New since v0.1.0-alpha

- **Programs start reliably.** v0.1.0-alpha lost about every third command.
  This image started 300 of 300 programs on a real Pi 3B+. It has two relibc
  fixes in the aarch64 signal entry, and its dynamic loader reads shared
  libraries byte by byte.
- **Firmware information** under `/scheme/rpi-firmware`:
  - `board`: model, revision, memory, serial
  - `temperature`
  - `throttled`: undervoltage and overheating flags
  - `clocks`

  Example: `cat /scheme/rpi-firmware/temperature`.
- **Clock.** The Pi has no battery-backed clock. At boot, `timesync` sets the
  time from the last saved time, or from the build time if there is none.
  Once the network is up it sets the time from `pool.ntp.org`, and it saves
  the time every hour.
- **Ethernet over USB (experimental):** a driver for the RTL8152 and RTL8153
  chips. They are on the Ethernet HATs and USB hubs for the Pi Zero 2 W and
  in many USB adapters. On a Pi 3B+, a plugged-in adapter takes over from the
  onboard Ethernet.
- **Pi Zero 2 W:** the same image boots on it. With an RTL8152 Ethernet hub
  it gets on the network and sets the clock from `pool.ntp.org`. It has no
  network without such an adapter, because Wi-Fi does not work yet.
- The build ID and the experiments in the image are shown above the login
  prompt.

## What works

- Boots from the SD card to a login prompt on HDMI.
- USB keyboard (US layout). `Super` + `F1` shows the boot log, `Super` +
  `F2` the login console.
- All four CPU cores.
- SD card: root filesystem, read and write.
- Onboard Ethernet on the Pi 3B+: DHCP and TCP.
- `reboot`.

## Known issues

- Some programs still stop at start with exit code 1 and no output. Most
  often this hits `ps` printed straight to the terminal (`ps | cat` works)
  and `reboot` (run it again). Tracked as T12 in
  [docs/tasks.md](https://github.com/redox-rpi/redox-rpi/blob/main/docs/tasks.md).
- A USB device plugged in after boot is not detected (T17). Plug the keyboard
  in before you power on.
- The CPU runs at 600 MHz instead of 1400 MHz: Redox does not ask the
  firmware for a higher clock yet.
- No Wi-Fi, Bluetooth, audio, USB storage or `poweroff`.
- The boot shows harmless messages about PCI (`pcid … panicked`) and audio
  (T18).
- Many prebuilt programs (bash, nano, vim, curl, …) do not start, so they
  are not in the image.

## Install

1. Download `redox-rpi-v0.2.0-alpha-pi3bplus.img.xz` and check it against
   `SHA256SUMS`.
2. Write it to a microSD card of at least 2 GB. Use Raspberry Pi Imager
   ("Use custom"), balenaEtcher or SwiftFlash, or on Linux and macOS:

   ```sh
   xz -dc redox-rpi-v0.2.0-alpha-pi3bplus.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync
   ```

   Everything on the card is erased.
3. Put the card into a Pi 3 Model B+ or Zero 2 W. Connect HDMI, a USB
   keyboard and Ethernet, then power on.
4. Log in as `root` with password `password`, or as `user` without a
   password.

## Built from

Build `v0.1.0-alpha-76-g4178ec5+x83a0`: Redox upstream at the commits in
[config/upstream.lock](https://github.com/redox-rpi/redox-rpi/blob/main/config/upstream.lock),
with this repository's patches and the experiments `ldso-diagnostics`,
`timesync` and `rtl8152`. The image's `/etc/redox-rpi-manifest` lists every
patch and package with its hash.

The new SD card driver (sdhost) is not in this release: started by hand on
a real Pi it hung. It comes back once it works as the boot driver.
