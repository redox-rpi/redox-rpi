## Build options

Built in `~/redox-rpi-rel` from one commit of `main`, without
`--allow-dirty`, as soon as PR #67 is merged. All rc2 patches are then
default patches; only `timesync` is still an experiment (it adds a package,
no patches). Checked on 2026-10-30: main cb3c588 + PR #67 (c71a6a5) merge
without a conflict, and `scripts/check-patches.sh` applies every default
patch (kernel 8, relibc 7, base 27, bootloader 2, fdt 1) and every
experiment to the pinned commits.

```bash
cd ~/redox-rpi-rel && git fetch -q origin && git checkout -q --detach origin/main
git log --oneline -1                     # the commit that becomes rc2: note it
OPTS="--release v0.3.0-rc2 --experiment timesync"
scripts/build-image.sh $OPTS             # netboot, Pi 3B+, for the automated tests
mkdir -p keep && cp upstream/redox/build/aarch64/minimal/harddrive.img keep/v0.3.0-rc2-netboot.img
scripts/build-image.sh --sdcard $OPTS    # release image (SD card, Pi 3B+ and Zero 2 W)
scripts/build-image.sh --zero2w $OPTS    # netboot, Zero 2 W (128 MiB image)
```

Then the QEMU check before queueing anything:
`DEVSH_PORT=12510 scripts/qemu-raspi3b.sh --usb-net --data --image keep/v0.3.0-rc2-netboot.img`
(`--data` from PR `qemu-data-part`, or a copy of that script) and
`scripts/pi-test.py 127.0.0.1 --port 12510 --starts 300`: all six checks
must pass.

If a branch named in the notes is not merged at build time, its items stay
under "Not in this candidate" in
[v0.3.0-rc2.md](v0.3.0-rc2.md).

Not in the release: `ldso-diagnostics` and devshd. The SD card config
(`config/raspi3bp-sdcard.toml`) has no devshd; the netboot images have it,
for `pi-test.py`.

Results go to `/srv/tftp/sdcard/` as `redox-rpi-v0.3.0-rc2.img.xz` with its
manifest and `SHA256SUMS`.
