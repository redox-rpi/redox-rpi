# v0.7.1 checklist

Status: **draft** (2026-11-28, build agent). A card-only release: the
programs of v0.7.0, with the root filesystem on the card instead of in a
RAM disk ([#786](https://github.com/redox-rpi/redox-rpi/issues/786),
PR #792). Mainly for the Zero 2 W (512 MB), where the RAM root takes much
of the memory. No tag and no release without the maintainer's OK, typed
by the maintainer in the build agent's session, on the exact commit.

## Plan (PM decision, 2026-11-28)

- Branch `release-v0.7.1` from tag `v0.7.0` (637c7514) with the commits
  of PR #792 (only `scripts/make-sdcard.sh`, `scripts/fw-direct-boot.sh`
  and docs). Pushed 2026-11-28 at `82169875` (#792's commits picked onto
  `v0.7.0` without conflict; these scripts did not change on `main`
  after `v0.7.0`).
- No new image build: the card is made from the v0.7.0 release-netboot
  image `v0.7.0-dev-120-g637c7514+x6a9f` with `make-sdcard.sh --direct
  --card-root`: RedoxFS as partition 3, the initramfs holds only initfs.
- Zero 2 W first; the 3B+ too if it works.
- Published in family `redox-rpi`, version `v0.7.1`
  (`sudo swiftflash redox:redox-rpi`).
