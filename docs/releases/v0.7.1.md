**Status: experimental (alpha). Not for daily use.**

v0.7.1 is a card-only release of Redox OS on the Raspberry Pi
([checklist](v0.7.1-checklist.md)). **It is meant for the Zero 2 W.** The
programs are those of [v0.7.0](v0.7.0.md); only the SD card is laid out
differently: the root filesystem is on the card instead of in memory.

This is an **unofficial, AI-assisted fork** and not part of the Redox OS
project. Please report problems here, not to Redox.

## New since v0.7.0

- **The root filesystem is on the card**
  ([#786](https://github.com/redox-rpi/redox-rpi/issues/786), PRs #792
  and #812). v0.7.0's card copied the whole system into memory at boot;
  v0.7.1 reads it from the card's third partition. On the Zero 2 W
  (512 MB) about 338 MB stay free after boot instead of about 113 MB.
  Changes to the root filesystem (passwords, files in `/home`, the time
  zone link) are kept across reboots.
- **The data partition is mounted at `/scheme/data`** on this card; the
  v0.6.0 and v0.7.0 cards did not mount it.

The card has three partitions: the boot files (FAT), the data partition
(960 MiB, `/scheme/data`) and the root filesystem (222 MiB).

## Known issues

As in [v0.7.0](v0.7.0.md#known-issues), except the direct-card items
about the root in memory. In addition:

- **The Pi 3B+ is untested with the root on the card.** It is expected to
  work (the SD driver is the same), but only the Zero 2 W was tested. For
  the 3B+, v0.7.0 is the tested release.
- An update with `rpi-update` replaces only the kernel and the startup
  files; the root filesystem on the card keeps its old version.
- Pull the power only after `poweroff`: the root and data partitions can
  be damaged otherwise.

## Install

1. With SwiftFlash on the test network: `sudo swiftflash redox:redox-rpi`
   and pick version `v0.7.1`. Or download `redox-rpi-v0.7.1-zero2w.img.xz`
   from this release and check it against `SHA256SUMS`.
2. Write it to a microSD card of at least 2 GB:
   `xz -dc redox-rpi-v0.7.1-zero2w.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync`.
   Everything on the card is erased.
3. Put the card into a Zero 2 W. Connect HDMI, a USB keyboard and, for
   the network, the Ethernet HAT or a USB Ethernet adapter, then power on.
4. Log in as `root` with password `password`, or as `user` without a
   password. `desktop` starts the desktop (beta).

## Built from

(`637c7514`) plus PR #792 (root on the card) and PR #812 (data partition),

the options of v0.7.0; every program file is the same as in v0.7.0.
