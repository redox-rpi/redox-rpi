## Before the candidate

- [ ] Merge-next pull requests merged, or moved to v0.8.0 (the lead keeps the order).
- [ ] Release options for rc1. The build agent proposes and **the maintainer
  decides**. Proposal: the options of v0.6.0, `timesync rpi-fb orbital
  orbital-apps cosmic-apps-source desktop tcc usb-port-power hdmi-audio`.
  The time zone needs no option since #709.
  **If PR #729 is merged** (usb-port-power as default base patch, #576), it
  removes the experiment directory: `usb-port-power` must then come out of
  the release options, or build-image.sh fails on the missing experiment.
  The same holds for the nightly options, if PR #727 (usb-port-power in
  `config/stable-image.conf`) is merged first.
- [ ] Patch overlaps between open pull requests, whichever merges second
  needs a rebase:
  - #694 and #729 both change `patches/experiments/dwc2d-restart/base/0084`.
  - #697 and #729 both add a base patch `0122`; the second one needs a
    new number (the duplicate check of #698 fails on it).
- [ ] Nightly of the cut-off evening green (build, pi-test). The nights of
  2026-11-24 and 2026-11-25 failed through #576; PR #727 adds
  `usb-port-power` to the nightly options.
- [ ] Build in a clean or updated clone.
- [ ] The upstream bump (#696) stays out of v0.7.0 (maintainer decision,
  2026-11-24); it is merged after the release.

## Candidate

- [ ] `v0.7.0-rc1` built from `main` after the cut-off, on the maintainer's
  OK on the exact commit.
- [ ] rc1 card as a **direct card** ([release process](../release-process.md#the-release-card-a-direct-card)),
  published, with the candidate checks.
- [ ] QEMU: regression set (`scripts/regression-qemu.sh --starts 300`) and
  the desktop check.
- [ ] REQ-REL-1 (no devshd) and REQ-REL-5 (size), with the direct-card
  checks of the [release process](../release-process.md#candidate-checks).
- [ ] Automated Pi test, 3B+ (pi-tests queue), on the rc1 network-boot test
  build: standard checks, regression set, 100 reboots with network (#576),
  out of memory (`oomtest`, #644), `date` in CET and `env TZ=UTC date`
  (#46), the release variant with no open port.
- [ ] **Zero 2 W without network ([#654](https://github.com/redox-rpi/redox-rpi/issues/654))**,
  on the rc1 Zero 2 W image: (a) boot with no USB network adapter, and
  (b) boot with an adapter but no cable. Each boot shows at most one
  `dhcpd` line on the serial console. With a cable plugged in after the
  boot, a lease follows. The serial log goes into a pi-tests report.
- [ ] Person test on the rc1 SD card by the maintainer, Pi 3B+ and Zero 2 W:
  login, network and clock in local time, desktop, Sopwith with sound over
  HDMI.
- [ ] Notes `docs/releases/v0.7.0-rc1.md`.
