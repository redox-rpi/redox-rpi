# Topics

One page per topic: what works, what is being worked on, what comes next.
The tasks themselves are [GitHub issues](https://github.com/redox-rpi/redox-rpi/issues), labelled `topic:<name>`.
Whoever works on a topic keeps its page current, in the same commit as the
change ([CONTRIBUTING.md](../../CONTRIBUTING.md#topics-and-issues)).
